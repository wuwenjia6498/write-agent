# 书目：《长袜子皮皮》阅读指导核心价值

## 一、 核心教育价值

### 1. 人物形象的深层解读

皮皮是一个外表怪异但内心金子般纯净的女孩。她满头红发、小辫子翘向两边、脸上布满雀斑，穿着一只棕色一只黑色的长袜子，鞋子比脚大一倍。这些外在特征背后，隐藏着更重要的精神品质：

- **坚强与乐观**：父亲在海上失踪，母亲早逝，皮皮却对想象中的妈妈说"不要为我担心，我会料理自己的"。她将失去父母的悲伤转化为积极生活的动力，独自照顾自己，努力学习做饭（尽管方式古怪）。
- **善良与慷慨**：拥有取之不尽的金币，却常用来买糖果和玩具分送给孩子们。力大无比，能举起马、制服小偷强盗，但从不用力气伤害他人，只在帮助别人或保护自己和其他孩子时才施展力量。
- **独立与自主**：在维拉·维洛古拉独自生活，按自己的愿望安排日常，体现了儿童对自主、自由和快乐的向往。

### 2. 友谊的真谛

皮皮与杜米、阿妮卡的友谊展现了相互付出的深度：

- **皮皮的付出**：为照顾朋友感受编造"树上长汽水"的美好谎言；在朋友生病时天天隔窗表演；面对分别时不停讲笑话逗他们开心；最终为了朋友放弃航海计划留在维拉·维洛古拉。
- **朋友的回应**：杜米和阿妮卡能关注到皮皮不常流露的脆弱一面，在分别时阿妮卡"趴在木箱上放声大哭，仿佛心都被撕碎了"，杜米为她念告别诗。
- **成人态度的转变**：杜米和阿妮卡的母亲最初因皮皮不合常规的行为而不接受她，但被皮皮对孩子们的贴心关怀感动后，最终允许孩子们跟随皮皮航海。

### 3. 成长中的重要品质

- **游戏精神**：皮皮能将平凡日子变得有趣，创造出一个孩子们喜欢的、没有约束、完全自由的世界。
- **正义感**：惩罚不公，为孤寡老人准备丰盛圣诞晚宴，保护霍屯督岛上的孩子。
- **真诚表达**：虽然行为古怪，但内心渴望被接受，努力表现热情（尽管方式不被大人理解）。

## 二、 核心阅读策略

### 1. 透过行为看本质

引导孩子不要停留在人物的表面行为，而要深入分析行为背后的动机和情感：

- **"说谎"的真相**：皮皮说树上能长汽水和巧克力饼干，实际是她自己准备的。这种"谎言"没有恶意，是为了让朋友的日子更有趣。当要离开时，她说"这个季节不长汽水"，是为了不让朋友因找不到食物而失落。
- **古怪行为的理解**：做烙饼时把鸡蛋打在头上、面糊溅得到处都是，不是故意捣乱，而是因为没有大人教导，她在努力学习照顾自己。

### 2. 关注细节中的情感线索

教会孩子捕捉文本中不直接表达的情感：

- **眼神的描写**：杜米观察到皮皮的眼睛"完全跟上次我害大病时妈妈的眼睛一样"——充满担忧和绝望，揭示了皮皮面对分别的真实感受。
- **动作的含义**：皮皮"回头看了维拉·维洛古拉一眼"、提议"步行去，这样可以多拖一些时间"，这些细节都在诉说她的不舍。
- **圣诞场景**：书末皮皮"用做梦一般的眼睛看着前方"，引导孩子思考她在想什么——可能是对父母的思念，对朋友的珍惜，或对未来的憧憬。

### 3. 多角度理解人物

从不同人物视角理解主人公：

- **孩子们的视角**：最初觉得皮皮"怪怪的"，后来成为最要好的朋友，发现她的善良和有趣。
- **成人的视角**：女教师最初觉得皮皮"太不像话"，了解身世后不再生气；杜米和阿妮卡的母亲从不接受到被感动而接受。
- **作者的视角**：通过译者后记了解林格伦创作这个角色的初衷——希望女儿（和所有孩子）坚强、乐观，拥有无拘无束的快乐童年。

### 4. 人物推论方法

系统分析人物的四个维度：

- **想法**：皮皮说"多好的房子，没有跳蚤，各方面都称心如意"，表达对维拉·维洛古拉的留恋。
- **感受**："不忍心在这个绿色的地球上有人为我哭泣和伤心，特别是杜米和阿妮卡"，显示她对朋友的深切关爱。
- **行为**：从跳板上跑回来，把朋友的手放在自己手里，最终决定留下。
- **与他人的关系**：和杜米、阿妮卡是很要好的朋友，愿意为他们改变决定。

## 三、 经典细节与启示

### 1. 外貌描写的写作技巧

作者对皮皮外貌的描写生动形象，值得学习：

"她头发的颜色像胡萝卜一样，两条梳得硬邦邦的小辫子直挺挺地竖着。她的鼻子长得像小土豆，上边布满了雀斑。鼻子下边长着一张大嘴巴，牙齿整齐洁白。她的连衣裙也相当怪，那是皮皮自己缝的。原来想做成蓝色的，可是蓝布不够，皮皮不得不这儿缝一块红布，那儿缝一块红布。"

- 使用比喻（头发像胡萝卜、鼻子像小土豆）
- 注重细节（一只棕色袜子、一只黑色袜子）
- 交代背景（衣服是自己缝的，鞋子是爸爸在非洲买的）

### 2. 做烙饼的场景

这个场景集中体现了皮皮的特点：

- **游戏精神**：边做烙饼边说绕口令，把鸡蛋抛到空中，用浴刷搅拌面糊，把烙饼抛到半空中翻面。
- **想象力**：编造"蛋黄对头发特别好"、"巴西人都把鸡蛋涂在头发上"的故事。
- **独立生活**：虽然方式古怪，但确实在努力照顾自己。

### 3. 秘密基地的意义

大树根部的空心隐蔽室是三个孩子的专属空间：

- 皮皮在里面准备汽水和巧克力饼干，说是"树上长出来的"。
- 杜米担心别人发现这个秘密，因为这是属于他们的独特乐园。
- 当皮皮要离开时，杜米和阿妮卡说"永远都不会再来维拉·维洛古拉"，因为没有皮皮，这里就失去了意义。

这个细节说明：真正的友谊需要共同的秘密和专属的空间，这些是友谊亲密度的象征。

### 4. 告别场景的情感层次

分别时的描写层层递进：

- **语言层面**：杜米"声音有点儿哽住了"，阿妮卡"觉得有一只冰冷的手放在她的心上"。
- **行为层面**：阿妮卡"仔细打量着她，要把皮皮的样子牢牢记住"，"趴在木箱上放声大哭"。
- **集体层面**：镇子所有孩子用陶瓷口笛吹奏欢送曲，"曲调的悲伤难以形容"。
- **皮皮的反应**：不停讲笑话，提议步行以"多拖一些时间"，最终从跳板上跑回来。

### 5. "顽童"形象的文学价值

皮皮属于儿童文学中的"顽童"形象，与《淘气包埃米尔》《疯丫头马迪根》《小飞人卡尔松》《汤姆·索亚历险记》《彼得·潘》等作品的主人公相似：

- **共同特点**：奇特的想法、怪异的做法、搞笑的语言、另类的外貌，无拘无束，不受束缚。
- **深层意义**：顽皮、顽劣只是外在，内在拥有游戏精神、强大能力、善良品质和对朋友的真诚。
- **创作意图**：作者虚构这些"顽童"，是希望孩子们坚强、乐观，拥有无拘无束的快乐童年，同时保持善良和正义感。

### 6. 林格伦的创作背景

这本书的诞生源于母爱：

- 1941年，林格伦7岁的女儿卡琳因肺炎住院，每天晚上要妈妈讲故事。
- 女儿顺口说出"讲长袜子皮皮"这个名字，林格伦由此创造了这个角色。
- 1944年，林格伦把故事写出来作为女儿10岁生日礼物。
- 1945年参加出版比赛获一等奖，出版后获得巨大成功。

林格伦被称为"瑞典的民族英雄"，她的头像和皮皮的形象一同印在瑞典20克朗纸币上。以她名字设立的文学奖奖金达五百万瑞典克朗，是全球最大的国际儿童和少年文学奖。

### 7. 给中国孩子的启示

林格伦在篇首写给中国孩子的话："祝你们阅读愉快，继续读吧，直到把我的书全部读完。"虽然她因年事已高未能来中国，但一直关注着中国的事情。

这本书的艺术特色：

- 没有集中曲折的情节，而是以一系列儿童生活和游戏场面的生动描绘为主。
- 让童话人物直接进入现实生活，或让人物进行非现实活动。
- 以环境的现实性衬托人物的幻想性，收到真中求幻、幻中求真的效果。
- 格调轻松活泼，语言亲切幽默，以儿童情趣取胜。

皮皮这个形象实质上是解脱了身心束缚、天性自然发展的儿童形象，反映了儿童对自主、自由和快乐的向往。
