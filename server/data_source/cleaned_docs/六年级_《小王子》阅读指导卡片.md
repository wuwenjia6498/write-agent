# 书目：《小王子》阅读指导核心价值

## 一、核心教育价值

### 1. 保持童真与想象力
- 儿童拥有成人难以企及的纯真视角，能够发现生命本真
- 童话世界中儿童始终比成人强大，敢于追寻天方夜谭般的幻想
- 成长过程中不应遗失对世界的好奇心和丰富想象力

### 2. 理解爱与责任的真谛
- 爱需要时间和精心付出才能建立深厚情感
- "正是我为我的玫瑰花费的时光，才使我的玫瑰变得如此重要"
- 对驯养过的东西永远负有责任，这是爱的本质
- 真正的爱让对方成为世界上独一无二的存在

### 3. 批判成人世界的功利性
- 成人世界充斥着物质虚荣、盲目空虚、虚伪麻木
- 人们被功利思想占领，精神和内心日益萎缩
- 成人只关注抽象数字而忽视问题本质，缺乏享受生活的能力
- 以貌取人、爱慕虚荣、自以为是等成人陋习值得警惕

### 4. 建立真诚的人际关系
- 真正的友谊建立在相似的价值观和真诚相待的基础上
- 朋友之间会互相教给对方道理，为分别而忧伤
- 即使分离,心中的牵挂能让漫天星星化作朋友的笑脸

## 二、核心阅读策略

### 1. 精读法的运用
- 逐字、逐句、逐段深入思考每个细节
- 勾画诗意浪漫和富有哲理的语句
- 理清故事要素：主人公、地点、事件发展脉络

### 2. 时间轴梳理法
- 按照小王子的星际旅行顺序整理故事
- B612号星球→国王的星球→爱虚荣者的星球→酒鬼的星球→商人的星球→点灯人的星球→地理学家的星球→地球
- 明确每个星球遇到的人物及其象征意义

### 3. 对比分析法
- 对比儿童世界与成人世界的差异
- 儿童：纯真美好、单纯可爱、天真友好、充满幻想
- 成人：物质虚荣、寂寞孤独、盲目空虚、虚伪麻木

### 4. 符号解读法
- 蟒蛇吞象的画：成人缺乏想象力，只看到帽子
- 装着绵羊的盒子：真正重要的东西用眼睛看不见
- B612号星球：每个人心中都有属于自己的精神家园
- 玫瑰花：独一无二的爱与责任
- 狐狸：教会"驯养"的智慧导师

### 5. 哲理语句收集法
- "只有用心才能看见，本质的东西用眼是看不见的"
- "语言是误解的根源"
- "正是你为你的玫瑰花费的时光，才使你的玫瑰变得如此重要"
- "在人群中间，你也会感到孤独"
- "一个人要是被驯养过，恐怕难免要哭的"

## 三、经典细节与启示

### 1. "驯养"的深刻内涵
- 驯养意味着"建立感情联系"，让彼此成为独一无二的存在
- 驯养需要耐心、仪式感、精心付出和负责任的态度
- 每天在固定时间相见，让等待的过程充满幸福的期待
- 驯养是双向的：小王子驯养狐狸的同时也被狐狸驯养
- 金黄色的麦田因为小王子的金发而变得有意义

### 2. 五千朵玫瑰的启示
- 小王子在地球花园看到五千朵玫瑰后感到伤心
- 狐狸教会他：那些玫瑰虽然美丽但空虚，因为没有建立情感联系
- 小王子的玫瑰独一无二，因为他给她浇过水、盖过罩子、遮过风障、除过毛虫
- 启示：真正的价值来自投入的时间和情感，而非外在的数量或美貌

### 3. 星球上的奇怪大人
- 国王：统治空无一人的星球，象征自以为是的权威
- 爱虚荣者：只听得进颂扬的话，象征虚荣心作祟
- 酒鬼：喝酒是为了忘记喝酒的羞愧，象征自我矛盾和逃避
- 商人：忙着数星星想要占有它们，象征贪婪和无意义的占有欲
- 点灯人：机械地执行命令，象征盲目遵守规则失去思考
- 这些大人都活在自己狭隘的世界里，失去了生活的真正意义

### 4. 沙漠中的水井
- 小王子和飞行员在沙漠中找到水井
- 这水"来自星光下的跋涉，来自辘轳的歌唱，来自臂膀的用力"
- 水已不只是维持生命的物质，而是"像礼物一样愉悦着心灵"
- 启示：人们在玫瑰花园里种出五千朵玫瑰，却没能找到自己要找的东西；而要找的东西，在一朵玫瑰或一点儿水里就能找到

### 5. 数字与本质的对立
- 成人介绍朋友关心年龄、体重、父亲收入等数字
- 成人介绍房子只说价值十万法郎，而非红砖、天竺葵、鸽子
- 成人只相信B612号小行星的编号，不相信小王子的存在
- 启示：成人只关注可量化的数字，忽视了事物的本质和生活的美好过程

### 6. 小王子的离别
- 小王子选择被毒蛇咬以回到自己的星球
- 他安慰飞行员：当你夜里望着天空，所有星星都会像在笑
- 飞行员拥有会笑的星星，小王子拥有五亿口水井
- 启示：真正的离别不是永别，心中的牵挂让彼此永远相伴

### 7. 简洁而深刻的语言风格
- 用明白如话的语言写出引人深思的哲理
- 对话简单自然，却蕴含深刻的人生智慧
- "所有的大人起先都是孩子，可是他们中间不大有人记得这一点"
- "沙漠这么美，是因为有个地方藏着一口井"
- "星星很美，因为有一朵看不见的花儿"

### 8. 孤独与陪伴的主题
- 小王子独自生活在小行星上，照料玫瑰和清理火山
- 他在宇宙中旅行寻找友谊和生命的意义
- "在人群中间，你也会感到孤独"道出人类的本质困境
- 但通过"驯养"建立的情感联系能够消解孤独
- 启示：人本质上是孤独的，但爱与责任让我们找到生命的意义和归属
