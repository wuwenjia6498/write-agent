# Role
资深 Prompt 工程师 / 搜索架构师

# Task
优化 `server/services/workflow_engine.py` 中 Step 2 (信息搜索) 生成网络搜索关键词 (Search Queries) 的 Prompt，彻底解决 AI 把“系统动作指令”误认为“搜索实体内容”的严重 Bug。

# Logic & Prompt Update Requirements
1. **定位代码**：找到 `workflow_engine.py` 中，在调用 Tavily 搜索前，让 LLM 根据用户需求生成 `search_queries` (搜索关键词) 的函数/逻辑。
2. **重写 Keyword Generation Prompt**：在生成关键词的 System Prompt 中，加入极其严厉的“反混淆”约束。请参考以下结构注入提示词：
   
   【搜索词提取铁律】
   你现在的任务是提取用于网络搜索的关键词。请务必区分“用户的核心教育痛点”和“写作动作指令”。
   - **绝对禁止包含的元指令词（黑名单）**：需求分析、怎么写文章、公众号、排版、字数、1800字、写一篇、生成等。
   - **必须提取的核心实体词（白名单）**：教育现象、心理学名词、具体的阅读方法、书单类型（例如：桥梁书、图像到文字过渡、二年级阅读畏难、儿童注意力机制）。
   - **优化策略**：生成的搜索词应该像一位专业教育工作者在知网或谷歌学术里的检索词。例如，如果用户说“写一篇二年级只看漫画不看纯文字书怎么办的公号文”，你的搜索词应该是 `["二年级 漫画 纯文字 过渡策略", "儿童图像思维向文字思维转变", "桥梁书 推荐 阅读指导"]`。

3. **异常熔断（可选）**：如果发现模型依然生成了含有“需求分析报告”等互联网 IT 类的不相关词汇，说明 Prompt 控制失败，需确保系统不会因为一次荒谬的搜索而导致后续文章完全跑题（可以通过在检索后增加简单的相关性过滤，或单纯依靠上述 Prompt 强力纠偏）。
