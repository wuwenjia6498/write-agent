# Role
资深全栈工程师

# Task
执行“样文库 (Sample Articles)”的降维重构。移除复杂的 AI 风格分析和标签系统，将其简化为纯粹的“标题+内容+频道”的文本存储库，并优化大模型的调用工作流。

# Step 1: 前端 UI 极简改造 (app/admin/samples 或相关页面)
1. **移除分析与标签显示**：在样文列表卡片中，删除“重新分析”按钮、删除“已分析”状态标签、删除底部所有蓝灰色的“风格标签”展示区。仅保留样文标题、字数、来源和正文预览。
2. **简化添加弹窗**：在“添加样文”的表单中，删除任何关于“标签”、“自动分析”的选项或加载状态。只需要保留三个必填项：【标题】、【正文内容】、【归属频道】（小学/绘本/育儿）。提交即保存，不再调用分析接口。

# Step 2: 后端 API 清理 (server/routers/samples.py 或相关路由)
1. 找到负责“分析样文风格”的接口（例如 `POST /analyze` 或在新建样文时触发的 LLM 分析逻辑），**直接删除该接口及对应逻辑**。
2. 新建或更新样文只需纯粹的数据库 CRUD 操作，将 `title`, `content`, `channel_scope` 存入数据库（保留原有的 tags 字段允许为空即可，不用改库表结构）。

# Step 3: 工作流调度更新 (server/services/workflow_engine.py)
1. 在生成初稿 (Step 7) 调取样文的代码处，改为：根据当前任务的 `channel_scope`，从数据库中**随机抽取 1 到 2 篇**该频道的样文。
2. **更新 Prompt 注入机制**：不需要再传递任何样文的“标签”给大模型。只需将这 1-2 篇样文的标题和前 1000 字（避免超长）拼接成 `【排版与语气参考样文】` 区块。
3. **更新 System/User Prompt**：
   明确指示：“请仔细阅读并体会【排版与语气参考样文】的行文节奏、段落长短、语气语调（如：温润亲切或专业客观）。在接下来的创作中，请**严格模仿这种风格**进行输出，但绝不要照抄样文的具体业务内容。”
