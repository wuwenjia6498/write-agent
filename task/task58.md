# Logic & Prompt Update Requirements
1. **定位代码**：找到 `workflow_engine.py` 中组装 `execute_step_7` 提示词 (Prompt) 的逻辑。
2. **注入【开场白最高红线】与【多样化策略】**：在让 LLM 撰写初稿的 System Prompt 中，强力插入以下内容：

   【关于文章开头的最高红线】
   1. **绝对禁止“无中生妈/生爸”套路**：严禁使用“最近收到一位妈妈的留言”、“前几天有位家长问我”、“在家长群里看到”等虚构的读者提问作为文章开头。这种方式极度虚假且刻意。
   2. **禁止陈词滥调的焦虑渲染**：不要用“你家孩子是不是也这样...”作为生硬的引入。
   
   【强烈推荐的高级开场策略（请随机选择一种）】
   为了彰显老约翰品牌的专业与自然，请优先使用以下高级开场方式：

   - **策略 C：直击核心概念**（直接从文章的核心教育理念切入。如：“从‘看图’跨越到‘看字’，是小学低年级阅读中最关键，也是最容易卡壳的分水岭。”）
